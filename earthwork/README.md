# 土方挖填量计算系统（软件算例）

Vue 3 + Three.js 前端，FastAPI + SciPy/Shapely 后端，PostgreSQL/PostGIS 存储
（无数据库时自动回退本地 JSON）。**结果为软件算例量，不替代现场计量认定。**

## 1. 计算原理（口径可追溯）

1. **限定范围内 TIN**：SciPy `Delaunay`（qhull Qbb Qc Qz）对二维点建网，
   每个三角片与 Shapely 边界多边形求交。裁剪交点高程只沿**已有三角片线性内插**，
   边界外区域不建网、不补点、不趋势外推（`app/tin.py`）。
2. **双曲面叠加**：原地面 TIN 与设计面 TIN 的边 node + polygonize 生成叠加单元，
   单元内两面各为平面，差值 `dz = z_ground − z_design` 为线性函数，
   单元 earcut 后逐片精确积分（`app/overlay.py`、`app/volume.py`）。
3. **挖、填分别积分**：零挖填线半平面裁剪，线性函数多边形积分
   `V = A·(dz₁+dz₂+dz₃)/3`。净量 `cut−fill` 仅作平衡参考，
   **不用净体积掩盖同时存在的大量挖方与填方**。
4. **三种口径并列**：TIN 精确积分 / 规则网格角点法（多档精度对比）/
   断面法（断面面积梯形过渡）。断面图中原地面、设计线分别绘制，
   缺测点断开，不连线、不补高程。
5. **统一基准是硬前提**：平面坐标系不一致 → pyproj 转换；API 直接拒绝未统一的提交
   （422）。高程基准之间无纯数学关系，只接受水准联测/拟合得到的显式偏移
   （`app/crs.py`，`apply_vertical_offset` 必须 `confirmed=True`）。
6. **质量问题显式列出**：精确重复点、同坐标高程矛盾、退化三角片（面积≈0/质量2r/R
   极低）、边界外点、跨缺测空区的瘦长大片，全部在“数据检查”中给出（`app/qc.py`）。

## 2. 内置软件算例（可手算复核）

| key | 场景 | 手算结果 |
|---|---|---|
| `plane` | 100×100 场地，zg=0.05x，zd=0.05y，零线 x=y | cut=fill=0.05·100³/6 = **8333.333 m³**，净 0 |
| `hole` | 中央 20×10 边界孔洞（跨零线） | cut=**8275.00**，fill=**8325.00**，面积 9800 |
| `gap` | 填区 20×30 局部缺测并显式圈出 | cut=**8266.67**，fill=**8116.67**，面积 9400 |
| `rolling` | 起伏地形 | 三维展示 / 网格精度对比 |
| `qc` | 重复点/高程矛盾/边界外点 | 数据检查清单验证 |

孔洞扣减（可积分复核）：挖方扣 0.05·(20³−10³)/6 = 58.333，
填方扣 0.05·10³/6 = 8.333。

## 3. 从汇总量下钻

界面右侧总量卡片 → “三角片下钻”表（点击行或直接在三维场景点三角片）
→ 该片顶点坐标、原地面/设计高程、dz、片挖填量。每行都带来源原地面三角片号。
历史计算（口径参数 + 完整结果 JSON）存 `compute_runs`，可逐次追溯。

## 4. 启动

```bash
pip install -r requirements.txt        # 后端
cd frontend && npm install             # 前端
bash run.sh                            # 同时启动
# 前端 http://127.0.0.1:5173 ，API 文档 http://127.0.0.1:8765/docs
```

PostGIS：`docker compose up --build`，或
`export EW_PG_DSN="postgresql://user:pwd@host:5432/db"`。
表结构见 `app/db/schema.sql`（XYZ 点、方案边界、重复点检查视图、计算运行存档）。

测试：

```bash
python3 -m pytest tests/ -q
```

## 5. 导入真实数据

界面“导入XYZ点”：每行 `x,y,z[,编码]`（逗号/空白/Tab 分隔），
可指定源/目标 EPSG 做平面转换。或 `POST /api/parse-xyz`
（multipart：file、surface、source_crs、target_crs）。
边界孔洞用 GeoJSON 风格环（外环逆时针、洞顺时针）在方案 JSON 中给出。

## 6. 重要边界说明

- 任一面 TIN 凸包外、边界/孔洞/缺测环内的区域**一律不计**；界面显示未覆盖面积。
- 网格角点法角点落在缺数据单元时该单元弃用（格数 `采用/总数` 可见）。
- 网格越粗偏差越大（40m 档在手算案例上偏差 −42%，10m 档约 0.5%），
  精度对比表如实呈现，不粉饰网格法。
- **本系统输出为软件算例，用于设计复核与方案比选，最终工程量以现场实测、
  监理签认与合同计量规则为准。**
